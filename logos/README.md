# Culture Hop Tours — propositions de logos

Ouvrir `index.html` pour comparer les quatre pistes, ou `comparatif.png` pour un apercu unique. Chaque dossier contient un logo SVG, une icone SVG et leurs apercus PNG transparents. Les polices du SVG sont editables ; des variations sont possibles selon les polices installees.

1. Globe voyageur : voyage et etapes.
2. Porte des cultures : accueil et patrimoine.
3. Liens et rencontres : cultures et personnes connectees.
4. Monogramme CH : signature compacte.

Les propositions sont preparees pour validation. Elles ne remplacent pas automatiquement le logo de navigation. L'onglet utilise une icone dediee simplifiee et le titre Culture Hop Tours.

## Choix actuel

La proposition 04, monogramme CH, est maintenant utilisee sur le site et dans l'onglet du navigateur. Voir CHOIX_ACTUEL.md.

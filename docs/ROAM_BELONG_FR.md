# Roam & Belong

Nom de marque : **Roam & Belong**. Domaine retenu d’après la recommandation fournie : **roamandbelong.com**. Le logo typographique place un cœur bleu avec une petite rose de navigation entre Roam et Belong ; le symbole SVG est aussi utilisé comme favicon.

Le nom est configurable dans les réglages globaux. La migration `0044` applique le nouveau nom au site existant. Les coordonnées email restent celles déjà renseignées ; aucune adresse professionnelle fictive n’a été créée.

Les réglages de domaine, le fichier `.env.example` et Render sont prêts pour `https://roamandbelong.com`. Sur un hébergement déjà déployé, remplacer également la variable `MOROCCO_SITE_URL` si elle est déjà définie. Cette variable historique désigne l’URL publique du site global. La configuration DNS et le rattachement du domaine dans l’hébergeur restent à effectuer : aucune publication ni modification DNS n’a été faite ici.

Les images du carrousel changent automatiquement toutes les cinq secondes. Le survol et le focus ne l’arrêtent plus ; les boutons de navigation et Pause/Play sont retirés. La minuterie ignore les onglets masqués et reprend au retour. Les images restent configurables dans Global website settings → Homepage hero slides.

# Image fixe de la barre d’accueil

La barre « Many cultures. Unforgettable journeys. » utilise une seule image décorative fixe, sans carrousel ni animation. Le titre reste un texte HTML lisible.

Image finale : `static/img/roam-belong-banner.webp` (2172 × 724), générée avec l’outil intégré **imagegen**, inspectée puis encodée en WebP pour le site. Les motifs sont illustratifs : aucune promesse de destination ou de service précis.

La feuille CSS globale reçoit un nouveau suffixe de version pour éviter que le navigateur conserve l’ancien bandeau. Le fond est défini dans `.home-title-bar` dans `static/css/global.css`.

Prompt final utilisé :

> Create an original ultra-wide decorative website title-strip background for the travel brand Roam & Belong. Asset type: a single static panoramic raster banner, approximately 5:1 composition, not a webpage mockup. Refined editorial illustration in deep midnight teal and blue-green, with delicate warm sand-gold and sky-blue engraved lines. At the far left, understated layered dunes, an abstract arch and a palm silhouette; at the far right, ocean waves, soft mountain contours and subtle route lines. These elements suggest many cultures and meaningful travel without depicting a specific monument. Large central 65 percent remains very dark, uncluttered and calm for crisp white HTML headline text overlaid later. Sophisticated, welcoming, subtle woven-paper texture, low visual noise, flat luminous line art, professional travel brand identity. No words, letters, logos, watermarks, borders, UI controls or people. Entire canvas opaque. The decorative motifs should remain visible when cropped into a shallow 176-pixel-high strip.
